- NSLS2/OceanOptics:
    - Issues:
        - [x] [Driver status and AreaDetector support](https://github.com/NSLS2/OceanOptics/issues/1)
            - LNLS evaluated another driver from the Central Laser Facility, based on
              [Cornell's driver](https://gitlab01.classe.cornell.edu/jad/oceandirect).
              It is based on AD, while NSLS2's isn't, and it uses the OceanDirect SDK.
                - We noticed it's missing relevant features, e.g.:
                    - Temperature control
                    - Hardware feature probing
                - We're leaning towards implementing AD support for NSLS2's OceanOptics
                  instead
            - Mark: it might be worth considering that OceanDirect is supported while
              SeaBreaze is stagnated for a decade.
            - Jakub didn't know about OceanDirect, and he wouldn't be against porting
              OceanOptics to this SDK if the interface is similar
            - Jakub: there are patches in his fork of SeaBreeze that implement new
              features more than building to recent distributions. Thus, the
              OceanOptics driver requires the patched version indeed.
